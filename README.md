# bets-service

Microservicio de apuestas de **fijazoo**: CRUD de apuestas e importación/exportación de Excel.

Es la **fuente de verdad** del sistema: `user_statistics`, `user_progression` y el ranking son
proyecciones derivadas de las apuestas que viven aquí.

Extraído del monolito `fijazo-api` como Fase 3 de la migración a microservicios (tickets T-019 a
T-023). La documentación completa de contratos y variables llega en el ticket de documentación.
